About this map

The data comes from projects published in the DesignSafe Data Depot Repository and their public Hazmapper maps. DesignSafe is the cyberinfrastructure of the NSF-funded Natural Hazards Engineering Research Infrastructure (NHERI) (Rathje et al., 2017, doi:10.1061/(ASCE)NH.1527-6996.0000246). Each map links to its published project, which gives the dataset's DOI and citation.

  • Project locations: 262 of the 1,680 projects published in the Data Depot Repository have a location. Snapshot taken 28 Oct 2026.
  • Hazmapper features: GeoAPI published-maps archive.
